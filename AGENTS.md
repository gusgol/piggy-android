# Repository guidance for coding agents

Before making architecture, data-model, mapping, navigation, or module-boundary changes, read the canonical [architecture guide](docs/architecture/ai-guidance.md).

For tasks that add or move features, repositories, models, mappings, or modules, follow the [Piggy architecture skill](.agents/skills/piggy-architecture/SKILL.md). It provides the change workflow; the architecture guide is the single source of architectural rules.
